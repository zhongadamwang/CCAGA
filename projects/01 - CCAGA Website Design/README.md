## Workflow Integration
This project follows the EDPS (Evolutionary Development Process System) methodology:

### Requirements Processing
1. **Ingest**: Use requirements-ingest skill to normalize requirements from various sources
2. **Extract Goals**: Use goals-extract skill to identify business objectives and success criteria
3. **Analyze**: Use process-w5h skill for comprehensive stakeholder analysis

### Domain & Process Modeling
4. **Extract Concepts**: Use domain-extractconcepts skill to identify core business entities
5. **Align Entities**: Use domain-alignentities skill to map with existing organizational models
