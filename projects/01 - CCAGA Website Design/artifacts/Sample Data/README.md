# Sample Data

## Purpose
Test data, examples, and sample content for the CCAGA Website Design project.

## Content Types
- Sample website content and copy
- Test user data and personas
- Mock data for development and testing
- Example images and media files
- Configuration examples

## Organization
- `content/` - Sample website content and text
- `users/` - Test user profiles and personas
- `media/` - Sample images, videos, and assets
- `config/` - Configuration file examples

## Usage
Sample data supports:
- Development environment setup
- User testing scenarios
- Content migration planning
- Performance testing with realistic data volumes

## Guidelines
- Use anonymized and fictional data only
- Ensure compliance with privacy requirements  
- Maintain realistic data volumes for testing
- Document data sources and generation methods
